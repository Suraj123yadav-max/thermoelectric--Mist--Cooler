# 🌡️ Thermoelectric Mist Cooler — Design & Prototyping

A thermal-management prototype developed using **Autodesk Fusion 360 and 3D Printing**, focusing on CAD modelling, prototype fabrication, geometry validation, and assembly fit.

---

## 📌 Project Overview

The **Thermoelectric Mist Cooler** project focused on designing and prototyping a thermal-management system using **Autodesk Fusion 360** and **3D printing**.

The project involved converting the design concept into a 3D CAD model, preparing the components for fabrication, and developing a scaled physical prototype to validate the design geometry and assembly fit.

The project was carried out in collaboration with a **PhD scholar at IIT Indore** as part of an ongoing thermal-management research project.

---

## 🎯 Objectives

The primary objectives of this project were:

- To develop a CAD model of a thermoelectric mist-cooling system.
- To design components using **Autodesk Fusion 360**.
- To prepare the design for 3D printing.
- To fabricate a scaled physical prototype.
- To validate component geometry and assembly fit.
- To gain practical experience in CAD modelling and rapid prototyping.
- To contribute to an ongoing thermal-management research project.
